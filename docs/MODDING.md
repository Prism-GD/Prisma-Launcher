# Prisma Modding

Prisma mods use the `.prism` package extension and Prisma's own package manifest.

- Read the [Draft 1 package specification](PRISM_PACKAGE_FORMAT.md).
- Start with the [minimal manifest example](../examples/minimal/manifest.json).
- Do not rename Geode or Noahh packages to `.prism`; their formats and runtime APIs are not interchangeable.

The format is currently a draft. Package installation and native execution are not implemented yet.
