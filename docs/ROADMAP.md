# Prisma Launcher Roadmap

This roadmap is a starting point and will change as technical decisions are validated.

## Phase 1 — Foundation
- [x] Create repository and project documentation
- [ ] Choose Android language, UI framework and minimum SDK
- [ ] Define supported Geometry Dash versions and architectures
- [ ] Establish build and CI workflow

## Phase 2 — Launcher
- [ ] Implement launcher shell and navigation
- [ ] Detect installed Geometry Dash versions
- [ ] Add settings, logs and diagnostics

## Phase 3 — Mod management
- [ ] Define a documented mod manifest/package format
- [ ] Build catalog and local mod library
- [ ] Implement install, enable, disable, update and uninstall flows
- [ ] Validate packages and compatibility metadata

## Phase 4 — Independent runtime
- [ ] Research supported game integration points
- [ ] Implement an original runtime/loader architecture
- [ ] Add version-specific compatibility checks
- [ ] Test with a minimal proof-of-concept mod

## Phase 5 — Release
- [ ] Automated builds and release artifacts
- [ ] Upgrade and recovery paths
- [ ] Documentation and initial public test
